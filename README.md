# Celebrare Photo Gallery

A simple and responsive photo gallery built with React, Vite, and Tailwind CSS as part of the Celebrare assignment.

### Features

* Fetches 30 photos from the Picsum Photos API.
* Search photos by photographer name.
* Add and remove photos from favourites.
* Saves favourites using localStorage.
* Responsive layout for desktop, tablet, and mobile.
* Loading spinner and error handling.

### Tech Stack

* React
* Vite
* Tailwind CSS
* JavaScript

### Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in the terminal.

### API

https://picsum.photos/v2/list?limit=30
